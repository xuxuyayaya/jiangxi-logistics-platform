# 界面内容与优先级复核（2026-11-13）

## 首页的首要任务

统一入口按实际业务顺序组织：发布需求 → 规划联运 → 匹配资源 → 跟踪运输。首屏显示四项动作、运输状态和待办；运行驾驶舱独立置于顶栏。公共政策、资源服务和产业场景与业务流程互通，不以“政府 / 企业”两块介绍牌占据首页。

依据：规划V2第32—34页与用户提供的建设规划、物流综合服务和多式联运截图；PRD POR-003服务目录与POR-004工作台、消息与订阅；民营企业调研提出使用路径不清晰，应优先高频刚需。政府治理关注通过驾驶舱、预警、政策与数据服务承接，不以身份分区代替具体功能。

## 页面安排

- 工作台：快捷操作、运输概览、待办、近期运单，随后是六类产业场景、政策提醒和资源概况。
- 运行驾驶舱：地图居中，两侧为运输结构、任务状态、节点能力与风险；区域与运输方式筛选同步更新统计。指标来源为当前演示台账，不使用官方总量名义。
- 资源目录：按设施 / 运力本身分类，不能因为仓库位于铁路园区就配火车图。分普通仓、冷库、公路车辆、冷藏车、铁路、水运、装卸等类型，展示数量、温区、覆盖、来源及状态。
- 政策、接口、工单、能力目录：以内容、流程、状态和动作表达，取消无关的港口或仓储装饰照片。
- 产业场景：脐橙、蜜桔、现代家具、铜材、粮油、新能源各自使用对应实物照片；图片仅作为同类场景参考，不暗示为某一家江西企业现场。
