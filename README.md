# 江西物流一张网 · 可运行演示平台

前端：原生JavaScript + 响应式CSS。后端：FastAPI。数据库：SQLite。浏览器通过后端API加载、创建和流转业务，不是纯静态页面。

## 启动

Python 3.12环境：

```
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

管理账号 `admin`，企业账号 `enterprise`，初始演示密码均为 `Demo@2026!`。部署前设置 `DEMO_ADMIN_PASSWORD` 和 `DEMO_ENTERPRISE_PASSWORD` 可替换初始账号密码。密码只在数据库首次初始化时读取，已有数据库需另行执行受控重置。

## Render部署

将目录内容推送到GitHub仓库，在Render新建Blueprint，选择仓库中的render.yaml。或创建Python Web Service，build命令为 `pip install -r requirements.txt`，start命令为 `uvicorn app:app --host 0.0.0.0 --port $PORT --proxy-headers`，健康检查 `/health`。

默认free计划不含持久盘，重启或重部署可能丢失新业务数据并恢复演示种子。保留业务数据需选择支持磁盘的付费实例并挂载 `/var/data`，设置 `DATA_DIR=/var/data`。本项目没有自行开通付费资源。后续多实例生产环境应迁移PostgreSQL。

高德地图：在Render环境设置 `AMAP_WEB_KEY`（Web端JS API Key）、`AMAP_SECURITY_CODE`（安全密钥），控制台配置实际onrender.com域名白名单。JS Key为浏览器可见凭证；不得使用服务端Web服务密钥代替。无Key时明确展示模拟网络示意图。

## 业务范围

包含管理/企业登录、隔离数据、运行看板、需求发布、参考报价、资源登记审核、联运估算、运单分段事件、模拟单据打印及PDF另存、政策演示自测、预警状态流转、接口模拟监控、工单处理、CSV导出、审计及53项PRD能力索引。

全部数据、政策、轨迹、价格、时效和单据为模拟。运输求解为演示成本估算，不是完整路网优化器。接口监控使用种子数据，没有实际连接政府、铁路、港口或企业生产系统。53项目录是需求索引，非全部已实现的生产功能。

公开部署的演示站请勿上传真实个人信息或商业数据。当前账号为展示用途，不具备生产账号管理、密码找回、第三方认证、精细字段授权、审计防篡改等完整生产保障。投产须单独实施对应PRD并完成安全与业务验收。

## API

`/docs`提供OpenAPI。核心接口：`/api/login`、`/api/me`、`/api/data/{kind}`、`/api/quotes`、`/api/plans`、`/api/export/{kind}`、`/api/audit`。Cookie使用HttpOnly、SameSite=Strict，HTTPS请求设置Secure；密码PBKDF2散列；状态变更校验版本和业务状态，操作留审计记录。

## V1.1：订单路线详情

运输需求及运单行均可点击进入独立详情页，地址示例 `/#order/waybills/JX-2026-0036`，支持刷新和浏览器前后导航。后端 `/api/routes/{kind}/{id}` 为每条记录生成对应路线、分段、节点事件、模拟载具、费用与单据清单；继承原记录访问权限。

页面提供左侧分段、中部地图、右侧位置和事件、下方六类详情页签。可点击分段聚焦、点击节点定位、拖动进度、播放或暂停模拟路线、切换回放速度、下载路线JSON、查看打印模拟运单、发起关联工单。默认使用OpenStreetMap底图（Leaflet，带来源署名）；配置高德后优先用高德，GPS坐标经其转换接口处理。底图服务失败自动退回可操作的SVG路线示意。外部服务仅用于底图，不向其传输订单主体或商业明细。

路线连接线与采样点为演示数据，不是路网导航结果或设备GPS实测轨迹；所有页面均明确标识。尚未产生真实交接文件的附件显示待补充，不伪造下载文件。

参考站已实际查看：shulian-ll 的横向导航、四类任务入口、白底卡片工作台和全程跟踪地图；wrc-szpt 的登录、横向业务导航及监管工作台。参考站部分数据面板存在加载或权限状态，未复制其账户、素材、真实数据或密钥。本站采用独立AI港口图及江西模拟数据。

## V1.2：真实道路规划与供需匹配

`AMAP_WEB_SERVICE_KEY` 用于服务端高德坐标转换和V5道路路线查询，Key不会发送浏览器；`AMAP_WEB_KEY`和`AMAP_SECURITY_CODE`用于地图展示。道路里程、时长、道路名与指引来自高德响应，标注查询时间。缺Key、失败或无路线时不生成替代连线或数值。铁路、水运货运段需另外接入权威线路，不能以驾车结果替代。模拟GPS回放已停用，等待实际轨迹数据源。

`/api/matching/{demandId}`展示需求货量、时效、起讫和模式，及供方类型、可用/总容量、单位、硬约束、评分、适配范围和报价口径。运力吨位与仓储面积分开，多式联运的公路资源仅表示可匹配公路段。已关闭需求不再生成可承接推荐。

## V1.3：跨区域业务与专业工作台

需求可登记江西省内、跨省/全国及国际/跨境业务，起讫地支持自由输入；路线节点可按序录入，运输段可标注公路、铁路、水路等方式。未知地名先尝试高德地理编码；不能解析时不落到默认江西坐标、不画错误路线。公路段采用高德实路规划；铁路/港航显示计划段和接驳信息，实线路径需接入铁路/港口数据。新增全国及国际模拟演示订单，均明确为模拟业务。

政策服务、预警协同、数据接入和服务工单使用各自的流程工作台，分别呈现申报与核验、分级处置、接口监控、工单流转；产品能力目录按业务域展开PRD场景、规则、字段、验收及规划边界。导航与字号按桌面工作台重新调整，卡片使用按业务主题绘制的轻量矢量插图。
